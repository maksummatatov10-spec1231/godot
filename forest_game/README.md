# WARDEN — The Emerald Wild

Самостоятельная 3D-тестовая игра для **Godot 4.7.2 Standard**, без .NET, Rust,
C++, внешней библиотеки ассетов или дополнительных плагинов. В ZIP находится
редактируемый проект, не готовый Windows EXE. Архив распаковать целиком.

## Запуск

1. Установить Godot 4.7.2 stable (Standard).
2. В менеджере проектов нажать **Import** и выбрать этот `project.godot`.
3. Дождаться первого импорта моделей/шейдеров. Нажать **F5**.
4. Курсор захватывается автоматически. Escape освобождает его; клик возвращает.

Нужна desktop-видеокарта с поддержкой Godot **Forward+**. OpenGL fallback
намеренно выключен: он не даёт ту же графику. Проверка на программном Vulkan
не является замером FPS на вашем железе. Если тяжело — **F6 → Balanced**.

## Управление

| Кнопка | Действие |
|---|---|
| WASD | Плавная ходьба относительно направления камеры |
| Мышь | Обзор; камера со смещением через плечо в третьем лице |
| Shift | Бег в свободном третьем лице |
| Space | Прыжок с переходами start / air / landing |
| V | Первое / третье лицо |
| Правая кнопка мыши | Двигаться лицом по направлению камеры / прицеливание |
| Левая кнопка мыши | Удар мечом; последовательные удары A / B / C |
| Q | Магический снаряд с эффектом огня и ударной областью |
| F6 | Ultra / Balanced |
| R | Полностью перезапустить сцену |
| Escape | Освободить / захватить курсор |

Герою добавлены тёмно-зелёная одежда, перчатки/ботинки на основе исходной UV-текстуры
и причёска из набора Universal Base Characters. Меч прикреплён к `hand_r` реального скелета. В третьем лице используются
скелетные анимации Universal Animation Library: idle, walk, sprint, jump,
приземление, серия меча и заклинание. Переходы смешиваются, направление поворота
и ускорение сглаживаются. При ходьбе спиной в режиме прицеливания locomotion
проигрывается в обратном направлении; в свободном режиме тело разворачивается
по движению, как у camera-relative third-person контроллера.

В первом лице тело/голова скрыты только для этой камеры, чтобы не видеть лицо
изнутри. Используется отдельный viewmodel из **реальных skinned рук того же персонажа**
с теми же анимациями и мечом на кости кисти. Положение предплечий корректируется после анимации, чтобы локти не проходили
через объектив; пальцы и хват остаются скелетными. Это производная full-body анимаций,
а не отдельный профессионально отснятый FPS animation pack.
Смена камер и игровой hit detection общие для обоих режимов.

## Лес и графика

Дневной **стилизованный** лес из предоставленного Stylized Nature MegaKit:
лиственные деревья, сосны, кусты, папоротники, трава, цветы, камни, пологий
рельеф и тропа, небольшая декоративная вода. Фиксированный seed сохраняет
композицию при каждом запуске. Ветер двигает листву и траву.

Ultra включает Forward+, directional cascaded shadows, мягкие тени, SSAO,
SSR для отражений, volumetric fog, glow, filmic tonemapping и MSAA 2×. Это
качественный тестовый профиль, **не утверждение «все переключатели на максимум
всегда лучше»**. SDFGI не включается бездумно поверх динамических сцен.
280 деревьев сгруппированы в пространственные MultiMesh-батчи; 3400 экземпляров
травы/цветов также используют MultiMesh; дальняя мелкая трава ограничена
дистанцией, её тени отключены. Balanced убирает volumetric fog / SSAO / SSR
и MSAA, сохраняя игровой процесс и обычный атмосферный туман.

Звук: оригинальные синтезированные ветер/птицы, шаги, взмах и магия.
Это не записанный живой лес и не лицензированная фоновая песня.

## Боевой стенд

Три древних каменных стража — **тренировочные мишени, не вражеский AI**.
Меч наносит 34 урона в близкой фронтальной области, только в момент контакта.
Магия наносит 70 урона с проверкой пересечения луча между предыдущей и новой
позицией снаряда; нельзя пролететь сквозь цель на высокой скорости. Перезарядка
2.5 секунды. Страж показывает попадание/здоровье и восстанавливается через
4 секунды после разрушения. Здоровье героя в этом тестовом стенде декоративное:
мишени не атакуют его. Мир ограничен тестовой областью, не бесшовный open world.

## Проверки

Из корня проекта с установленным Godot:

```sh
godot --headless --path . --editor --import
godot --headless --path . --fixed-fps 60 --quit-after 1800 --script res://tests.gd -- --self-test
# Реальная графика, не headless; абсолютный существующий/создаваемый output:
godot --path . --rendering-method forward_plus --fixed-fps 30 -- --capture-dir=/absolute/output
```

`tests.gd` проверяет физику, все направления движения, обе камеры, прыжок,
приземление, реальное попадание мечом и снарядом, cooldown, восстановление целей
и переключение графики. Наличие PNG не подменяет эти тесты. Снимки третьего /
первого лица, меча, магии, прыжка, ходьбы и общего вида сохраняются отдельно,
затем открываются и просматриваются агентом. Точные результаты, source commit
и изображения опубликованы в основном GitHub-репозитории в `docs/evidence/forest-game/`.

Это игровой прототип/вертикальный срез, а не игра масштаба или бюджета GTA V.
Windows/macOS экспорт, баланс и аппаратная производительность требуют отдельных
прогонов на соответствующем железе; не выдаём их за уже выполненные тесты.
