# WARDEN — исправление лишней работы и новый профиль High · v0.3.1

Это исправления после сообщения о среднем FPS около 22. Физическая RX 580 пользователя недоступна: **не заявляем, что на ней измерены 60 FPS или окончательно установлен единственный источник просадки**.

## Скачать / запустить

ZIP — редактируемый Godot **4.7.2 Standard / Forward+** проект, не Windows EXE. Распаковать полностью, импортировать `WardenForest/project.godot`, дождаться импорта и нажать F5.

**Esc → Настройки → Графика → Высокий** — обновлённый профиль. Если раньше был сохранён Ultra, он останется Ultra: переключите на High для проверки. Трава не удалена; её тени — отдельная опция.

## Исправления

- Убрана тройная оценка анимации: основной скелет вычисляется один раз, руки и ноги получают готовую позу. Скрытые first-person скелеты/IK вообще не обновляются в третьем лице. Исходные A/B/C, ходьба, бег, прыжок, пальцы и общий сокет меча сохранены.
- High: карта теней **2048 вместо 4096**, PCF вместо дорогих PCSS-контактных мягких теней, без смешивания каскадов. Тени деревьев/героя/травы и SSAO сохранены; SSAO работает в половинном разрешении с меньшим качеством выборки.
- High: FXAA без дополнительного MSAA 2×. Ultra оставлен как более дорогой вариант с MSAA, PCSS, 4096 atlas, объёмным туманом и SSR.
- Ячейки деревьев переиспользуют геометрию/LOD вместо создания отдельных копий для каждой ячейки; дальность/LOD привязаны к центру каждой ячейки. Деревьев всё ещё 280, исходная густота травы сохранена.
- Неактивные VFX-пулы отключают обработку узлов; при использовании снова включаются. Это не замена прогрева: подготовка эффектов перед игрой сохранена.

## Теперь можно определить ограничение на своём ПК

**Esc → Настройки → Графика → Найти узкое место: 12 сравнений (~60 сек.)**

Одинаковый фиксированный ракурс; временно отключаются по одному разрешение/постэффекты/тени/деревья/трава/анимация/VFX, отдельно воспроизводится прежний дорогой High и его варианты без PCSS/MSAA. В конце повторяется база для выявления нестабильной нагрузки. Настройки восстанавливаются, есть отмена. Снижение стоимости кадра показывается как кандидат, не как безусловный аппаратный диагноз.

Отчёт **`user://performance-diagnostic.json`**: устройство и CPU, разрешение/масштаб, среднее/p99, CPU render/GPU timestamps (если доступны), число draw calls/примитивов и стоимость обновления анимации. Кнопка после теста открывает папку. Прежний 22-секундный тест с магией сохранён и дополнен CPU/GPU контекстом.

Если FPS остаётся низким, пришлите этот JSON: одно число «22 FPS» не отличает GPU, CPU, драйвер, разрешение и фоновые процессы. Производительность software Vulkan в CI не переносится на RX 580.

Включена прежняя Pose Lab (`WardenForest/model_lab`, Node.js 22.12+ нужен только для лаборатории). Известные визуальные ограничения переноса third-person клипов в FPS ещё остаются; эта ревизия посвящена производительности, а не обещанию идеального нового FPS mocap.

## Проверено перед публикацией

[Успешный прогон](https://github.com/maksummatatov10-spec1231/godot/actions/runs/43752469497): **47 игровых проверок, 22 настоящих Forward+ кадра, 12 A/B-этапов**. Python suite: **50 тестов**. Чистая распаковка ZIP прошла импорт и все 47 игровых проверок. Снимки High/Ultra, первого/третьего лица и обновлённого меню открыты и просмотрены.

В software Vulkan сцена с новым High дала 1006,88 мс/кадр против 1692,55 мс с реконструированными прежними GPU-настройками High — примерно **на 40,5% меньше времени кадра**. Это не сравнение старого и нового EXE на RX 580. Полное удаление травы в этом тесте дало около 7%; заморозка анимации почти не повлияла на render throughput. Деревья/тени оказались существенно дороже. Данные и ограничения — [в отчёте](https://github.com/maksummatatov10-spec1231/godot/tree/arena/449f84de-godot/docs/evidence/performance).
