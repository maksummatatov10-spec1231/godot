## WARDEN — Pose Lab + animation revision · v0.3.0 preview 1

**Предварительная ревизия, не заявление «FPS-анимации и хват окончательно идеальны».** В отдельных фазах удара C и прыжка остаются неестественные изгибы рукава/пересечения рук. Это явно видно на опубликованных кадрах. Предыдущая стабильная поставка v0.2 остаётся доступна отдельно.

### Что входит в ZIP

- Самостоятельный редактируемый проект **Godot 4.7.2 Standard / Forward+**, не Windows EXE. Распаковать целиком → `WardenForest/project.godot` → дождаться импорта → F5.
- **Pose Lab** в `WardenForest/model_lab`: на Windows запустить `start-windows.cmd` с установленным Node.js 22.12+. Первый запуск скачивает npm-зависимости; затем открыть http://localhost:5173. Для самой игры Node.js не нужен.
- Лаборатория: 14 реальных клипов, play/pause, покадровая перемотка, скорость, third/FPS/крупный план ладони, орбита, трансформы меча числами и манипулятором, экспериментальные вращения костей, сохранение PNG.
- Кнопка сохранения пишет общий `combat_pose.json`; после перезапуска Godot использует ту же настройку меча в обеих камерах. Экспериментальные повороты костей не экспортируются в игру.

### Изменения игры

- Удалена подмена FPS-ударов одной процедурной синусоидой. A/B/C, ходьба, бег, прыжок и приземление идут из исходных клипов.
- Один основной AnimationPlayer задаёт фазу; каждый кадр позы всех костей, включая пальцы и неключованные каналы, копируются в FPS-руки/ноги перед камерной IK-коррекцией.
- Производная FPS-модель содержит руки от плеч до пальцев, не короткие отрезанные запястья.
- Сокет меча откалиброван в лаборатории по закрытым пальцам: рука держит верхнюю часть рукояти под гардой, а не нижний конец. Положение `[-0.03, 0.104, -0.08]`, поворот `[90, 0, 0]`, масштаб `0.52` — одинаково в двух видах.
- Сохранены меню/настройки, дневной лес, тени героя/травы, отдельное отключение птиц, пул/прогрев VFX и встроенный аппаратный benchmark.

**WASD / Shift / Space / V / ЛКМ / Q / ПКМ / Esc** — движение, бег, прыжок, камера, меч, магия, прицеливание, пауза.

### Проверки и ограничения

38 игровых проверок; 50 Python-тестов; повторная выборка всех 14 клипов в браузерной лаборатории без накопления предыдущей IK-позы. Реальные Godot Forward+ кадры, точный исходный commit и логи — [в evidence](https://github.com/maksummatatov10-spec1231/godot/tree/arena/449f84de-godot/docs/evidence/forest-game). Браузерная лаборатория использует WebGL/Three.js, а не Forward+; её кадры не выдаются за скриншоты движка.

Не гарантируется нулевая задержка предпросмотра или FPS на RX 580: физическая видеокарта не тестировалась. CI использует software Vulkan. Для своего ПК используйте тест в настройках графики.

2D-архив исследован **отдельно** и в этот ZIP не включён. Каталог всех 15 вложенных архивов и найденные условия лицензий — [здесь](https://github.com/maksummatatov10-spec1231/godot/tree/arena/449f84de-godot/docs/assets-2d). Не все наборы CC0; жанр будущей игры ещё не выбран.

ZIP не содержит `.godot`, `node_modules`, Chromium или исходный 2D-пак. `BUILD_MANIFEST.json` содержит commit и контрольные суммы файлов, соседний `.sha256` — сумму ZIP. `model_lab/.gdignore` не даёт Godot импортировать npm-зависимости лаборатории.

[Проверенный прогон этой ревизии](https://github.com/maksummatatov10-spec1231/godot/actions/runs/43745736666): импорт, 38 игровых проверок и 21 Forward+ кадр прошли. Снимки просмотрены, включая крупный план хвата, A/B/C, ходьбу и фазы прыжка; оставшиеся дефекты не скрыты. В этом software Vulkan прогоне после прогрева DRAW 0→0, SURFACE 36→36, SPECIALIZATION 39→41 — это не аппаратный FPS-тест и не гарантия для другого драйвера.
