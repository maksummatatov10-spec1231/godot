# Фонарщик — ПК и Android · 0.4.0

## Скачать и запустить

- **Lantern-Valley-PC-Project.zip** — проект для ПК. Распакуйте, импортируйте `project.godot` в **Godot 4.7.2**, нажмите F5.
- **Lantern-Valley-Android-Project.zip** — тот же мир с мобильным профилем для F5 и готовыми настройками экспорта Android. Для запуска проекта нужен Godot; APK устанавливается отдельно.
- **Lantern-Valley-Android.apk** — подписанный установочный APK для **ARM64 и ARMv7**, без Godot на телефоне. Скачайте на Android, откройте файл и при необходимости разрешите установку из этого источника. Игра работает без разрешения на интернет.
- **Lantern-Valley-PC-Windows-x64.zip** — готовая сборка: распакуйте весь архив и запустите `Lantern-Valley.exe`. Исполняемый файл не имеет Windows Authenticode-подписи: Windows может показать предупреждение о неизвестном издателе.
- **Lantern-Valley-0.4.0-Screenshots.zip** — снимки игры, интерфейса и мобильного профиля. Отдельные `android-emulator-*.png` — снимки именно Android-эмулятора, а не физического телефона.

## Управление и настройки

Слева на телефоне — **аналоговый виртуальный джойстик, не крестовина**: ручка следует за пальцем во всех направлениях; малое отклонение даёт медленное движение, полное — полную скорость. Отпускание возвращает ручку в центр и останавливает героя. Справа — **Z / X / C**, дополнительно L (свет) и Q (предмет); второй палец может нажимать действия во время движения.

В **«Настройки → Экран и управление»**:

- включение **автобега**; он меняет скорость движения, но не заставляет героя идти без ввода;
- **«Расположение и размер»** — перетаскивание стика и каждой кнопки, изменение радиуса ползунком, сохранение/отмена/сброс;
- предел FPS, VSync, экономное или родное разрешение отрисовки.

Настройки сохраняются между запусками. Android Back ставит игру на паузу/продолжает; сворачивание сохраняет начатую игру и сбрасывает зажатый ввод. Сюжет, диалоги, сохранения, мир и направленные тени сохранены. Это отдельная 2D-игра, не изменение `forest_game`.

## Профили и границы проверок

**ПК:** окно Full HD 1920×1080, целевой предел 75 FPS. **Android:** альбомная ориентация с поворотом на 180°, по умолчанию предел 60 FPS/VSync, экономная отрисовка 640×360 с масштабированием, локальные карты теней и сон далёких животных.

Предел FPS — настройка, **не обещание частоты на конкретном устройстве**. Проверки включают реальные кадры Godot на Linux/Mesa, регрессии игрового процесса/сохранений/аналогового ввода, релизный экспорт Windows и Android, проверку подписи/манифеста/ARM ABI APK, а также отдельный **x86_64 Android-эмулятор** с системным свайпом, Back и сворачиванием/возвратом. Физический телефон, ARM runtime, физическая видеокарта и запуск в нативной Windows не проверялись.

APK подписан **тестовой preview-подписью**, не производственным ключом. Для обновления поверх установленной версии подпись должна совпадать. Не удаляйте старую установку ради смены подписи без резервной копии сохранений.

`SHA256SUMS.txt`, `BUILD-VALIDATION.json` и `ANDROID-VALIDATION.json` содержат контрольные суммы и сведения о сборке/проверках. Игра пока является ранней играбельной версией, а не завершённой RPG: нет боевой системы, инвентаря и интерьеров домов.
