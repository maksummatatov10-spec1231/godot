# WARDEN / Pose Lab

Интерактивная лаборатория реальных glTF-моделей героя, FPS-рук и меча. Это **Three.js/WebGL**, не встроенный Godot Forward+ и не универсальный редактор любых 3D-форматов.

## Запуск

Нужен Node.js **22.12+**. В Windows запустить `start-windows.cmd` либо выполнить в этой папке:

```sh
npm ci --omit=dev
npm run dev -- --port 5173
```

Открыть http://localhost:5173. Лаборатория работает как из репозитория рядом с `forest_game`, так и из распакованного ZIP внутри `WardenForest/model_lab`. Первый запуск устанавливает зависимости через интернет; затем модели читаются с диска. `npm run build` проверяет JS, но `dist` **не автономная версия**: нужны asset/API middleware dev-сервера.

## Возможности

- Все 14 исходных клипов, play/pause, скорость, точное время, шаг 1/30 секунды.
- Третье лицо с орбитой/масштабом/панорамой, фиксированная FPS-камера, крупный план ладони.
- Положение/поворот/масштаб меча: числа и 3D-манипулятор. Для равномерного масштаба используйте центральный куб или числовое поле.
- Выбор кости и XYZ-повороты поверх клипа для экспериментов. Они **не сохраняются в игру**; сброс отдельной кнопкой.
- FPS-компоновка: положение, поворот, масштаб всего viewmodel.
- PNG текущего 3D-вида одним нажатием; точное время видно рядом с ползунком.
- «Сохранить в игру» пишет общий `combat_pose.json`; перезапустите игру, чтобы загрузить изменения. Оно не экспортирует новые скелетные анимации.

Две копии меча имеют одинаковый локальный сокет и масштаб. FPS-коррекция подгоняет руки к камере двухкостным IK, но не подменяет A/B/C одним синусоидальным ударом. Источник анимации отделён от изменяемого скелета, чтобы повторная выборка того же кадра не накапливала IK.

Изменения видны в следующем отрисованном браузером кадре, без перезапуска Godot. «Мгновенно» не означает гарантированные 0 мс: скорость зависит от WebGL/GPU; переключение ракурса дешёвое после загрузки, полный реальный Forward+ рендер существенно медленнее на программном Vulkan CI.

## Известное ограничение

Перенос third-person клипов не равен специально снятому FPS mocap. В некоторых фазах C/прыжка остаются неестественный изгиб рукава, пересечение рук и низкое положение кисти. Лаборатория предназначена в том числе для выявления этих проблем; эта ревизия не объявляется финальным визуальным исправлением. Проверяйте не только один удачный стоп-кадр, но весь клип в обеих камерах.

Для автоматизированной проверки разработчика: `npm ci`, запустить сервер, `node capture.mjs` (Linux Chromium требует системных NSS-зависимостей). Результаты по умолчанию в `../artifacts/model-lab`. Игра использует свой suite `tests.gd` и реальные скриншоты Godot — браузерные изображения их не заменяют.
